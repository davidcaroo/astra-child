Test de Navbar - Emprende Sin Límites

Esta es una página de prueba para verificar el funcionamiento de la nueva navbar.

Características:

  • ✅ Logo a la izquierda
  • ✅ Menú de navegación centrado
  • ✅ Botones de acción a la derecha
  • ✅ Menú hamburguesa en mobile
  • ✅ Icono X para cerrar en mobile
  • ✅ Compatible con menús de WordPress
  • ✅ Responsive y moderno

Instrucciones de Prueba:

  1. Redimensiona la ventana para ver el comportamiento responsive
  2. En mobile (< 1024px), haz clic en el icono de hamburguesa
  3. El menú debe expandirse desde abajo
  4. El icono debe cambiar a una X
  5. Haz clic en la X o fuera del menú para cerrarlo
  6. Presiona ESC para cerrar el menú
