# Emprende Sin Límites - Astra Child Theme

Tema WordPress profesional para academia online de cursos de marketing, emprendimiento y ventas.

## 🚀 Características

- ✅ Diseño moderno y responsive
- ✅ Navbar con menú centrado y hamburguesa mobile
- ✅ Sistema de diseño completo con CSS variables
- ✅ Integración con Sensei LMS
- ✅ Bloques de contenido modulares
- ✅ Compatible con WordPress 6.0+
- ✅ Optimizado para SEO

## 📋 Requisitos

- WordPress 6.0 o superior
- PHP 7.4 o superior
- Tema padre: Astra
- Plugin recomendado: Sensei LMS

## 📦 Instalación

1. Instala y activa el tema Astra
2. Sube esta carpeta a `wp-content/themes/`
3. Activa "Emprende Sin Límites - Astra Child"
4. Instala Sensei LMS para funcionalidad de cursos

Ver [INSTALLATION.md](INSTALLATION.md) para instrucciones detalladas.

## 🎨 Estructura

```
astra-child/
├── assets/
│   ├── css/          # Estilos globales y utilidades
│   ├── js/           # JavaScript principal
│   └── images/       # Imágenes y logos
├── blocks/           # Bloques de contenido
├── inc/              # Funciones de integración
├── style.css         # Metadata del tema
├── functions.php     # Funciones principales
├── header.php        # Header personalizado
├── footer.php        # Footer personalizado
└── template-landing.php  # Template de landing page
```

## 🔌 Integración Sensei LMS

El tema incluye integración completa con Sensei LMS:

- Muestra cursos reales en la homepage
- Shortcode `[esl_courses]` para cualquier página
- Metadatos automáticos (precio, estudiantes, duración)
- Compatible con cursos gratuitos y de pago (WooCommerce)

Ver [SENSEI_INTEGRATION.md](SENSEI_INTEGRATION.md) para más detalles.
